# 上班族增肌减脂方案生成器

一个**单文件、无需安装、数据全部保存在本地浏览器**的增肌减脂方案生成工具。

## 在线使用

- 方案生成器（主）：https://fghsdh2.github.io/fitness-plan-generator/
- 减脂陪跑小程序（带人版）：https://fghsdh2.github.io/fitness-plan-generator/peipao.html

## 它做什么

三步生成个性化方案：

1. **基础信息** —— 性别/年龄/身高/体重、体脂率（含估算助手）、腰围、活动水平、运动基础、作息与压力、伤病、现有饮食习惯、饮食偏好
2. **目标设定** —— 减脂（按斤 / 按体脂率）或增肌，自动校验速率是否安全
3. **方案输出** ——
   - 饮食方案：完整计算过程（BMR→TDEE→缺口→营养素）、碳循环（含适配性判断与三档强度）、餐次建议、食物换算、食堂外卖点餐参考
   - 运动方案：居家版 / 健身房版、与碳循环对应的一周安排、伤病适配
   - 原理说明、常见问题、每周记录与自动调整

## 参考来源

方案中每个关键结论都标注了可追溯的来源（共 15 条），包括：

- 《中国居民膳食指南（2022）》准则一~五（中国营养学会官网）
- 《成人体重判定》WS/T 428-2013（腰围标准）
- ISSN 蛋白质立场声明、ISSN 体成分立场声明、Helms 2014
- Deurenberg 1991（体脂率公式）、Nedeltcheva 2010（睡眠与减脂）
- Mifflin-St Jeor 基础代谢公式、ACSM 运动代谢方程
- 《中国食物成分表 标准版（第 6 版）》

视频/博主提供的经验性内容（碳循环比例、微微饥饿感）在界面中**单独标注为经验性方法**，不与文献结论混同。

## 隐私

所有输入只保存在使用者自己的浏览器本地存储中，不上传任何服务器。页面不含任何统计代码或第三方请求。

## 免责声明

本工具输出的是基于公开指南与文献的**一般性健康建议，不构成医疗处方、诊断或治疗意见**。
如有基础疾病、处于孕期哺乳期、有进食障碍史、正在服药，或为未成年人/高龄老人，请先咨询医生或注册营养师。
